NBA Data Lake

This repository contains the setup_nba_data_lake.py script, which automates the creation of a data lake for NBA analytics using AWS services.

Overview

The script performs the following actions:

  • Creates an Amazon S3 bucket to store raw and processed data.
  • Uploads sample NBA data (JSON format) to the S3 bucket.
  • Creates an AWS Glue database and an external table for querying the data.
  • Configures Amazon Athena for querying data stored in the S3 bucket.

Prerequisites

Before running the script, ensure you have the following:

  • Create a free account on Sportsdata.io and obtain an API key.
  • Ensure the IAM role running the script has permissions for S3, Glue, and Athena.

Setup Instructions

Step 1: Open AWS CloudShell

Go to AWS and sign in to your account. Open CloudShell.

Step 2: Create the Python Script

nano setup_nba_data_lake.py

Copy the script content from GitHub and paste it into the file.

Step 3: Create the .env File

nano .env
SPORTS_DATA_API_KEY=your_sportsdata_api_key
NBA_ENDPOINT=https://api.sportsdata.io/v3/nba/scores/json/Players

Step 4: Run the Script

python3 setup_nba_data_lake.py

Step 5: Verify Resources

Check the S3 bucket, verify uploaded data, and run queries in Amazon Athena.

Sample Query

SELECT FirstName, LastName, Position, Team
FROM nba_players
WHERE Position = 'PG';
